# 📊 LTIFR Dashboard

A Streamlit-based interactive dashboard to calculate and visualize **Lost Time Injury Frequency Rate (LTIFR)**.  
This tool is designed to help HSE (Health, Safety & Environment) teams analyze workplace incidents efficiently.

---

## ✨ Features
- 🧮 **LTIFR Calculator** → Input manual LTI & Work Hours, auto-calculate LTIFR  
- 📂 **Excel Upload** → Upload data (`Bulan, LTI, Jam_Kerja`) + additional columns supported  
- 📊 **Visualization** → Choose chart type: Line, Bar, or Pie  
- 📥 **Export to PDF** → Generate structured PDF reports with tables and charts  
- 🎨 **Modern UI** → Built with Streamlit for simplicity & interactivity
